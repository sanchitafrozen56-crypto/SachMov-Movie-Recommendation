# 🎬 SachMov - Movie Recommendation Website

SachMov is a modern movie recommendation website built using HTML, CSS, JavaScript, and TMDB API. It allows users to discover popular movies, search for their favorite titles, view ratings, and explore movie information with a Netflix-inspired user interface.

## ✨ Features

* 🔍 Search Movies
* 🎬 Browse Popular Movies
* ⭐ Movie Ratings
* 🖼️ High Quality Movie Posters
* 🎥 Trailer Search Button
* 📱 Responsive Design
* 🌙 Netflix-Style Dark Theme
* ⚡ Fast and Lightweight

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* TMDB API

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/sanchitafrozen56-crypto/SachMov-Movie-Recommendation.git
```

2. Open the project folder

```bash
cd SachMov-Movie-Recommendation
```

3. Add your TMDB API key inside `script.js`

```javascript
const API_KEY = "YOUR_API_KEY_HERE";
```

4. Open `index.html` in your browser.
